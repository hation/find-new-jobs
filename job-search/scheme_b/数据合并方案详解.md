# 数据合并方案详解

## 🎯 问题背景

在BOSS直聘的数据采集中，我们遇到一个**核心难题**：
- **搜索接口**：返回列表数据，包含技能要求、福利待遇等字段
- **详情接口**：返回单个职位详情，包含职位描述、公司介绍等字段
- **两者字段不重叠**：搜索数据有的字段详情数据没有，反之亦然

这导致之前的合并方案要么**丢失字段**，要么**错误覆盖**。

## 🔍 问题分析

### **字段分布对比**
| 字段 | 搜索数据 | 详情数据 | 结果 |
|------|----------|----------|------|
| 技能要求 (`skills`) | ✅ 有 | ❌ 无 | **之前丢失** |
| 福利待遇 (`welfareList`) | ✅ 有 | ❌ 无 | **之前丢失** |
| 职位标签 (`jobLabels`) | ✅ 有 | ❌ 无 | **之前丢失** |
| 职位描述 (`postDescription`) | ❌ 无 | ✅ 有 | **之前可能被覆盖** |
| 公司介绍 (`introduction`) | ❌ 无 | ✅ 有 | **之前可能被覆盖** |
| 详细地址 (`address`) | ❌ 无 | ✅ 有 | **之前可能被覆盖** |
| 联系人信息 (`bossInfo`) | ❌ 无 | ✅ 有 | **之前可能被覆盖** |

### **之前的错误合并策略**
```python
# 错误：用搜索数据覆盖详情数据
merged_data = detail_data.copy()
merged_data.update(search_data)  # 这会覆盖职位描述等重要字段！
```

### **现在的正确合并策略**
```python
# 正确：智能合并，不覆盖
def merge_fields(search_fields, detail_fields):
    merged = {}
    
    # 详情数据优先（对于两者都有的字段）
    for key, value in detail_fields.items():
        if value:  # 详情数据有值
            merged[key] = value
    
    # 搜索数据补充（详情数据没有的字段）
    for key, value in search_fields.items():
        if key not in merged or not merged[key]:  # 详情数据没有或为空
            merged[key] = value
    
    return merged
```

```python
# 核心合并逻辑
def merge_job_data(search_job, detail_job):
    merged = {}
    
    # 1. 基础信息（详情优先）
    if detail_job and 'jobInfo' in detail_job:
        job_info = detail_job['jobInfo']
        merged['职位名称'] = job_info.get('jobName', '')
        merged['薪资范围'] = job_info.get('salaryDesc', '')
        # ... 其他基础字段
    
    # 2. 搜索结果特有字段（详情数据没有）
    if search_job:
        skills = search_job.get('skills', [])
        merged['技能要求'] = ', '.join(skills) if skills else ''
        
        welfare = search_job.get('welfareList', [])
        merged['福利待遇'] = ', '.join(welfare) if welfare else ''
        # ... 其他搜索特有字段
    
    # 3. 详情数据特有字段（搜索数据没有）
    if detail_job:
        merged['职位描述'] = detail_job.get('jobInfo', {}).get('postDescription', '')
        merged['公司介绍'] = detail_job.get('brandComInfo', {}).get('introduction', '')
        # ... 其他详情特有字段
    
    return merged
```
