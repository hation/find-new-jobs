### 步骤4：批量获取详情
```bash
# 创建详情目录
DETAILS_DIR="职位详情_恢复执行_$(date +%Y%m%d_%H%M%S)"
mkdir -p "$DETAILS_DIR"

# 获取前5个详情（立即执行，避免token过期）
for i in $(seq 1 5); do
    echo "[$i/5] 获取第 $i 个职位..."
    
    LINE=$(head -n "$i" all_security_ids_final.txt | tail -1)
    SECURITY_ID=$(echo "$LINE" | cut -d'|' -f1)
    JOB_NAME=$(echo "$LINE" | cut -d'|' -f2)
    PAGE=$(echo "$LINE" | cut -d'|' -f3)
    
    echo "   职位: $JOB_NAME (第$PAGE页)"
    
    # 获取详情
    boss detail "$SECURITY_ID" --json > "$DETAILS_DIR/detail_$i.json"
    
    # 检查是否成功
    if grep -q '"ok": true' "$DETAILS_DIR/detail_$i.json"; then
        echo "      ✅ 成功"
    else
        echo "      ❌ 失败"
        # 显示错误信息
        grep -i "error\|异常\|expired" "$DETAILS_DIR/detail_$i.json" | head -2
    fi
    
    # 延迟
    if [ $i -lt 5 ]; then
        sleep 1
    fi
done
```

## 🔧 故障排除

### 问题1：登录失败
```
症状: boss login --cookie-source chrome 失败
原因: Chrome浏览器未登录或cookie未写入磁盘
解决:
  1. 在Chrome浏览器中重新登录BOSS直聘
  2. 关闭Chrome浏览器
  3. 重新执行 boss login --cookie-source chrome
```

### 问题2：token过期
```
症状: 获取详情时显示"环境异常 (__zp_stoken__ 已过期)"
原因: token有效期只有3-5分钟
解决:
  1. 重新登录
  2. 立即执行获取详情（不要等待）
  3. 减少每次获取的数量（从5个改为3个）
```

### 问题3：获取详情失败
```
症状: boss detail 命令返回错误
原因: securityId无效或权限不足
解决:
  1. 检查securityId是否有效
  2. 重新登录获取新token
  3. 跳过失败的职位，继续下一个
```
