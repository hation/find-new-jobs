## ⚠️ **避免的问题和最佳实践**

### **1. JSON结构验证**
```python
# 错误：使用错误的路径
jobs = data['data']['list']  # ❌ 错误

# 正确：验证路径存在
if 'data' in data and 'jobList' in data['data']:
    jobs = data['data']['jobList']  # ✅ 正确
```

### **2. 注释行处理**
```python
# 错误：没有跳过注释行
for line in f:
    parts = line.strip().split('|')  # ❌ 会处理注释行

# 正确：跳过注释行
for line in f:
    line = line.strip()
    if not line or line.startswith('#'):
        continue  # ✅ 跳过注释行
    parts = line.split('|')
```

### **3. 数据格式验证**
