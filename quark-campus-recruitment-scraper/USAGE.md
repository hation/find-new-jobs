## 🔧 配置文件说明

### config.yaml
```yaml
# 筛选配置
categories:
  - 产品类
  - 运营类
  - 数据类
  - 市场拓展
  - 销售类
  - 游戏类
  - 金融类

# 输出配置
output:
  directory: "output"
  filename_prefix: "quark_real_positions"
  format: ["json", "excel", "report"]

# 反爬配置
anti_crawling:
  delay_range: [1, 3]  # 随机延迟秒数范围
  max_retries: 3       # 最大重试次数
  user_agents: [...]   # 用户代理列表

# 字段配置
fields:
  required:  # 12个目标字段
    - 岗位id
    - 岗位名称
    - 职位类别
    - 子类别
    - 办公地点
    - 所属部门
    - 更新时间
    - 学历要求
    - 工作年限
    - 职位描述
    - 职位要求
    - 岗位详情链接
  
  extracted:  # 已实现字段
    - 岗位id
    - 岗位名称
    - 职位类别
    - 子类别
    - 办公地点
    - 所属部门
    - 更新时间
  
  pending:  # 待实现字段
    - 学历要求
    - 工作年限
    - 职位描述
    - 职位要求
    - 岗位详情链接
```

## 🛠️ 故障排除

### 常见问题

#### Q1：筛选条件没有正确应用
**症状**：页面显示361个岗位而不是92个
**解决**：
1. 点击"清除"按钮
2. 重新按顺序点击7个类别
3. 等待页面刷新

#### Q2：数据提取不完整
**症状**：只提取到部分岗位
**解决**：
1. 检查提取逻辑是否支持所有岗位前缀
2. 验证页面快照是否完整
3. 检查岗位名称匹配规则

#### Q3：Excel文件无法打开
**症状**：Excel文件损坏或格式错误
**解决**：
1. 确保安装了openpyxl库
2. 检查数据格式是否正确
3. 尝试使用JSON文件查看数据
