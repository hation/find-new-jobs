## 📝 **使用示例**

### **新项目配置示例**
```python
# 在爬取器中配置统一导出
config = {
    "company_name": "你的公司",
    "company_website": "https://your-company.com",
    "output_dir": "output/unified_excel",
    "quality_config": {
        "min_completeness": 0.8,
        "auto_validation": True,
        "generate_csv": True
    }
}

exporter = UnifiedExcelExporter(config)
result = exporter.export_to_unified_excel(positions)
```

### **历史项目转换示例**
```python
# 转换旧格式Excel到统一格式
exporter = UnifiedExcelExporter(config)
result = exporter.convert_legacy_excel(
    legacy_file_path="output/old_format.xlsx",
    output_dir="output/converted"
)
```

## 🚨 **常见问题解决**

### **问题1: 列名不匹配**
**症状**: 导出后列名不是16个标准列名  
**解决**: 检查 `excel_column_mapping.yaml` 配置，确保字段映射正确

### **问题2: 工作表缺失**
**症状**: Excel文件缺少某些工作表  
**解决**: 检查 `STANDARD_SHEETS` 配置，确保7个工作表都配置

### **问题3: 数据清洗失败**
**症状**: 学历、经验字段显示原始文本  
**解决**: 检查数据提取规则，确保清洗逻辑正确

### **问题4: 文件无法打开**
**症状**: Excel文件损坏或无法打开  
**解决**: 检查pandas和openpyxl版本，确保使用正确版本
