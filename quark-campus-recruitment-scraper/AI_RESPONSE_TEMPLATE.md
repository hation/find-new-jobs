## 🔍 **验证步骤详细说明**

### **步骤1：信息完整性验证**
```python
# 伪代码：验证确认信息
required_info = [
    "列表页URL",
    "目标岗位", 
    "默认策略",
    "确认报告"
]

def validate_confirmation(user_message):
    missing = []
    for info in required_info:
        if info not in user_message:
            missing.append(info)
    
    if missing:
        return f"缺少信息: {missing}"
    else:
        return "验证通过"
```
