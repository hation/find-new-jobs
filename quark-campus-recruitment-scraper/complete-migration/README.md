## 🔧 核心业务框架（完整迁移独有的）

### **1. 智能爬取器选择器**
- 位置：`src/framework/smart_crawler_selector.py`
- 功能：API优先，浏览器备选，智能错误恢复，用户决策支持
- 价值：**业务选择逻辑的核心实现**

### **2. 统一爬取器入口**
- 位置：`src/framework/unified_crawler_entry.py`
- 功能：命令行参数解析，多种运行模式，状态查询，数据导出
- 价值：**项目入口和配置管理的核心实现**

### **3. 数据导出框架**
- 位置：`src/framework/data_exporter.py`
- 功能：支持Excel、CSV、JSON格式，数据验证和清洗，模板化输出
- 价值：**数据处理和导出的核心实现**

## 📞 技术支持

### **常见问题**
1. **Q: 迁移后业务框架无法导入？**
   A: 检查Python路径和依赖：`pip install -r requirements.txt`

2. **Q: 配置文件格式错误？**
   A: 使用验证脚本：`python scripts/validate_complete_architecture.py`

3. **Q: 如何定制业务框架？**
   A: 继承框架类并实现业务逻辑，参考示例：`src/examples/bytedance_migration_demo.py`

4. **Q: 迁移过程中断怎么办？**
   A: 使用`--force`选项重新运行，或手动清理目录后重试
