# 版本: 1.0

# 目的: 指导用户在新会话中正确启动夸克项目

## 📋 **问题背景**

### ❌ **AI助手的记忆限制**
AI助手在每次新会话中都是"重新开始"，会**忘记之前的所有信息**，包括：
- 🔗 **关键网址** (招聘网站地址)
- 🎯 **业务目标** (92个岗位、7个筛选类别)
- 📊 **数据规范** (12个字段)
- 🔧 **技术配置** (direct_url策略等)

### ✅ **解决方案**
建立**强制性业务信息加载系统**，通过**用户主动运行脚本**来确保AI读取正确信息。

## 🚀 **新会话标准操作流程**

### **第一步：用户必须执行的操作**
```bash
# 1. 打开终端，进入项目目录
cd ~/.openclaw/workspace/skills/quark-campus-recruitment-scraper

# 2. 🔥 运行强制性业务信息加载器
./MANDATORY_BUSINESS_LOADER.sh
```

### **第二步：复制确认信息到会话**
加载器运行后会输出类似这样的信息：

```
我已运行强制性业务信息加载器，确认以下信息:
✅ 列表页URL: https://talent.quark.cn/off-campus/position-list
✅ 目标岗位: 92个 (7个筛选类别)
✅ 默认策略: direct_url
✅ 确认报告: business_info_confirmation_20260519_222512.txt
```

**请将这段确认信息完整复制到与AI助手的会话中。**

### **第三步：AI助手验证和响应**
AI助手看到确认信息后，会：
1. ✅ **验证信息**：检查确认信息是否完整
2. ✅ **读取报告**：查看生成的确认报告
3. ✅ **恢复上下文**：基于业务信息建立决策上下文
4. ✅ **开始工作**：按照标准化流程开始工作

## 📋 **为什么需要用户操作？**

### **技术限制**
- AI助手无法在会话间保留记忆
- 用户运行脚本是"绕过"记忆限制的唯一可靠方法
- 通过用户操作确保AI读取正确的业务信息

### **质量保证**
1. **✅ 信息正确性**：用户运行脚本确保信息正确
2. **✅ 可验证性**：AI可以验证用户是否执行了操作
3. **✅ 一致性**：所有会话基于相同信息开始
4. **✅ 透明度**：用户知道AI基于什么信息工作

## 🔧 **加载器工作原理**

### **执行过程**
```
用户运行 MANDATORY_BUSINESS_LOADER.sh
    ↓
脚本读取 CORE_BUSINESS_INFO.md
    ↓
提取关键业务信息
    ↓
生成确认报告和会话标记
    ↓
输出确认信息供用户复制
    ↓
用户复制到会话中
    ↓
AI读取并验证信息
    ↓
开始工作
```

### **生成的文件**
每次运行加载器会生成：
1. 📄 **确认报告**：`business_info_confirmation_YYYYMMDD_HHMMSS.txt`
   - 证明业务信息已加载
   - 包含关键信息摘要
   - 用于AI验证

2. 🏷️ **会话标记**：`session_marker_YYYYMMDD_HHMMSS.txt`
   - 标记会话开始时间
   - 记录加载器版本
   - 用于会话跟踪

## 🛡️ **错误处理**

### **常见问题及解决**

#### **问题1: 脚本找不到**
```bash
# 确保在正确目录
cd ~/.openclaw/workspace/skills/quark-campus-recruitment-scraper
ls -la MANDATORY_BUSINESS_LOADER.sh
```

#### **问题2: 权限不足**
```bash
# 添加执行权限
chmod +x MANDATORY_BUSINESS_LOADER.sh
```

#### **问题3: 信息不完整**
如果加载器报告信息不完整：
```bash
# 检查核心业务信息文件
cat CORE_BUSINESS_INFO.md | head -30
```

#### **问题4: AI不响应确认信息**
如果AI没有正确响应确认信息：
1. **重新发送确认信息**
2. **附加确认报告内容**
3. **明确要求AI验证信息**

## 📊 **验证AI是否正确加载信息**

### **AI应该表现出的行为**
1. ✅ **确认收到信息**：明确表示已读取确认信息
2. ✅ **验证关键信息**：复述关键网址和业务目标
3. ✅ **检查当前状态**：读取 memory_checkpoints.json
4. ✅ **制定执行计划**：基于业务信息制定计划
5. ✅ **遵循决策框架**：按照标准化流程工作

### **AI不应该出现的行为**
1. ❌ **询问网址**：如果AI问"招聘网址是什么"，说明信息未加载
2. ❌ **询问目标**：如果AI问"要爬取多少个岗位"，说明信息未加载
3. ❌ **重新开始**：如果AI从头开始分析，说明信息未加载
