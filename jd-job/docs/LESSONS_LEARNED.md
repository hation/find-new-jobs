## 📁 教训分类索引

### 🚨 API相关问题
#### 认证失败
- **常见原因**: CSRF令牌过期、Cookie失效、API密钥无效
- **预防措施**: 定期验证认证信息、实现自动刷新机制
- **检查清单**: 在CHECKLIST.md中添加认证检查项

#### 数据解析错误
- **常见原因**: 响应结构变更、字段类型变化、编码问题
- **预防措施**: 添加响应结构验证、实现兼容性处理
- **检查清单**: 添加数据解析验证检查项

#### 分页逻辑错误
- **常见原因**: 相信URL参数而非页面显示、总页数计算错误
- **预防措施**: 以页面显示为准、添加页数验证
- **检查清单**: 添加分页逻辑检查项

### 🌐 浏览器相关问题
#### 页面元素变更
- **常见原因**: 网站改版、A/B测试、动态加载
- **预防措施**: 使用更稳定的选择器、实现元素检测
- **检查清单**: 添加页面结构检查项

#### 网络超时
- **常见原因**: 网络不稳定、页面加载慢、资源阻塞
- **预防措施**: 增加超时时间、实现重试机制
- **检查清单**: 添加网络稳定性检查项

#### 反爬虫机制
- **常见原因**: 验证码、频率限制、行为检测
- **预防措施**: 控制请求频率、模拟人类行为
- **检查清单**: 添加反爬虫检测项

### 📊 数据质量问题
#### 字段缺失
- **常见原因**: 数据源问题、解析错误、存储问题
- **预防措施**: 数据完整性检查、默认值处理
- **检查清单**: 添加数据完整性检查项

#### 数据重复
- **常见原因**: 分页重叠、数据源重复、处理逻辑错误
- **预防措施**: 去重机制、唯一性检查
- **检查清单**: 添加数据去重检查项

#### 格式错误
- **常见原因**: 编码问题、类型转换错误、格式规范变更
- **预防措施**: 格式验证、类型检查、兼容性处理
- **检查清单**: 添加数据格式检查项

### ⚙️ 配置问题
#### 环境配置错误
- **常见原因**: 环境变量缺失、路径错误、权限问题
- **预防措施**: 配置验证工具、环境检查脚本

- **常见原因**: 版本冲突、不兼容升级、依赖缺失

## 🔄 模板使用指南

### 快速开始
```bash
# 1. 复制模板
cp LESSONS_LEARNED_TEMPLATE.md LESSONS_LEARNED.md

# 2. 记录第一个问题
# 按照模板格式填写

# 3. 定期回顾
# 每周五下午回顾本周教训
```

### 记录原则
1. **及时性**: 发现问题立即记录
2. **客观性**: 事实描述，不指责
3. **完整性**: 按照模板填写所有信息
4. **可操作性**: 解决方案要具体可行
5. **可验证性**: 验证方法要明确

### 回顾机制
- **每日**: 快速浏览新记录的问题
- **每周**: 团队会议讨论重要教训
- **每月**: 生成分析报告，更新检查清单
- **每季度**: 系统性回顾，优化流程

### 与检查清单的联动
```markdown
# 教训 → 检查清单的转化流程
1. 记录教训
2. 分析根本原因
3. 制定预防措施
4. 更新CHECKLIST.md
5. 验证预防措施有效性
```

## 📋 预定义严重教训示例（来自蚂蚁国际项目）

### 问题ID: SYSTEM-FUNCTION-NOT-USED
**教训名称**: 系统功能未使用  
**严重等级**: 🔴 严重  
**发现时间**: 2026-05-22  
**来源项目**: 蚂蚁国际招聘爬取项目

#### 📝 问题描述
**标题**: 重新开发已有功能，未使用系统现有方案  
**现象**: 
- 遇到需求时，先想"怎么解决"而不是"系统里有什么"
- 重新发明轮子，开发已有功能
- 低估模板系统的完整性

**根本原因**: 
1. **思维模式错误**: 把夸克模板当作"参考架构"而不是"完整功能系统"
2. **认知偏差**: 认为"基于模板创建"等于"从模板开始开发"
3. **流程缺失**: 缺少"先检查系统功能"的关键步骤

#### 💡 解决方案
**立即措施**: 
1. 停止当前错误路径
2. 检查夸克模板系统的现有功能
3. 使用系统功能重新处理

**长期措施**: 
1. 在检查清单中添加"系统功能检查"项
2. 建立"系统优先"的工作原则
3. 从"开发者思维"转变为"系统使用者思维"

#### ✅ 预防措施
1. **检查清单增强**: 添加系统功能检查规则
2. **流程标准化**: 建立"系统优先"的工作流程
3. **培训强化**: 强调模板系统的完整性和使用方式

#### 🔗 相关检查项
```markdown
### 系统功能检查（最高优先级）
- [ ] **检查现有功能**: 遇到问题先检查夸克模板系统是否有解决方案
- [ ] **使用现有方案**: 优先使用模板系统的工具和脚本
- [ ] **避免重复开发**: 不重新发明轮子，除非有明确的新需求
- [ ] **配置优先**: 能通过配置解决的，不写新代码
- [ ] **系统思维**: 以系统使用者的角度思考，而不是开发者
```
