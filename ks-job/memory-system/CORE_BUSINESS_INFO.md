## 🎯 数据字段（12个核心字段）

### 1. 岗位ID (positionId)
- **描述**: 岗位的唯一标识符
- **格式**: 字符串或数字
- **示例**: "KS2024001"

### 2. 岗位名称 (positionName)
- **描述**: 岗位的完整名称
- **格式**: 字符串
- **示例**: "后端开发工程师"

### 3. 工作地点 (workLocation)
- **描述**: 岗位的工作城市
- **格式**: 字符串
- **示例**: "北京", "上海", "深圳"

### 4. 岗位类别 (positionCategory)
- **描述**: 岗位所属的技术类别
- **格式**: 字符串
- **示例**: "技术类", "产品类", "运营类"

### 5. 发布时间 (publishTime)
- **描述**: 岗位发布时间
- **格式**: 日期时间字符串
- **示例**: "2024-03-15 10:00:00"

### 6. 详情链接 (detailUrl)
- **描述**: 岗位详情页的URL
- **格式**: URL字符串
- **示例**: "https://job.ksyun.com/position/KS2024001"

### 7. 部门信息 (department)
- **描述**: 岗位所属的部门
- **格式**: 字符串
- **示例**: "快手主站技术部"

### 8. 学历要求 (educationRequirement)
- **描述**: 岗位要求的学历
- **格式**: 字符串
- **示例**: "本科及以上", "硕士及以上"

### 9. 工作经验 (workExperience)
- **描述**: 岗位要求的工作年限
- **格式**: 字符串
- **示例**: "应届生", "1-3年", "3-5年"

### 10. 工作职责 (jobResponsibilities)
- **描述**: 岗位的主要工作内容
- **格式**: 文本字符串（可能包含换行）
- **示例**: "负责快手主站后端系统开发..."

### 11. 任职要求 (jobRequirements)
- **描述**: 岗位的技能和经验要求
- **格式**: 文本字符串（可能包含换行）
- **示例**: "熟悉Java/Python，有分布式系统经验..."

### 12. 薪资范围 (salaryRange)
- **描述**: 岗位的薪资范围（可选）
- **格式**: 字符串
- **示例**: "20-40k", "面议"

## 🎯 技术架构

### API信息（基于你提供的信息）
1. **API地址**: `https://zhaopin.kuaishou.cn/recruit/e/api/v1/open/positions/simple`
2. **请求方法**: GET
3. **认证方式**: Cookie认证 + Sign签名
4. **核心参数**:
   - `pageNum`: 页码
   - `pageSize`: 每页数量（默认10）
   - `positionCategoryCode`: 岗位类别（J0005,J0004,J0013,J0006,J0014）
   - `positionNatureCode`: 岗位性质（C001=社招）
   - `recruitProject`: 招聘项目（socialr）
   - `workLocationCode`: 工作地点（domestic=国内）

### 爬取策略
1. **API优先**: 使用快手官方API获取数据
2. **智能分页**: 自动计算总页数，逐页爬取
3. **实时保存**: 每个岗位提取后立即保存到JSON文件
4. **断点续传**: 支持从上次失败点继续爬取

### 数据存储
1. **JSON格式**: 实时保存到 `output/ks_data/` 目录
2. **文件命名**: `ks_position_{id}_{timestamp}.json`
3. **数据备份**: 自动备份和版本控制

### 错误处理
1. **网络重试**: 最多3次重试机制
2. **API错误**: 处理快手API错误码
3. **数据验证**: 12字段完整性检查
4. **进度跟踪**: 实时显示爬取进度和统计信息
